Methodology & data sources

This analysis is built on the welzyn.FitnessNord_Catalog.product_360 view, which joins:

  • Actual sales (units, orders, revenue, margin) from welzyn.FitnessNord.prod_revenue — the daily order-fact table. EUR ex-VAT in storage; gross-up to incl-VAT applied at query time (DK 25%).
  • Current attributes (price, cost, stock, manufacturer, type, visibility) from the BoostmyShop BBD report endpoint, snapshot loaded 2026-05-04.
  • Parent linkage via parent_child_map (derived from prod_revenue.parent_product — covers 97–98% of bundles and configurables).

Filters applied throughout:

  • product_type_id IN ('simple', 'bundle', 'virtual') — configurables are display-only listings, never sold directly.
  • manufacturer != 'Test manufacturer' and product_form != 'Special categories' — excludes shipping methods that appear as catalog products in the raw BBD export.

Sanity-checked against order-level totals (DK + SE rolling 28d): catalog filter total 373.956 € vs order-level 373.043 € — 0,24% delta, within rounding.
