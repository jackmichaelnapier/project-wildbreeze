WildBreeze · The 11pm Spreadsheet Audit · v1.0

Find your first AI agent candidate.

Score one or more recurring tasks against the six questions below. The task that scores highest is your strongest candidate for an AI agent build.

Step 1 · The candidate task

What's the task? One sentence. Plain English.

Who currently does it? Name and role.

Step 2 · Six diagnostic questions

1. Does it run on a predictable schedule?

Daily, weekly, monthly, or event-driven? Pick one.

Score: 3 if predictable schedule. 1 if event-driven. 0 if "it depends."

2. Are the data sources tools with APIs?

List every system the task pulls from.

Score: 3 if every source is a modern SaaS or database. 2 if mostly. 0 if any sources are PDFs, scanned documents, or someone's email inbox.

3. Is the output structure stable from cycle to cycle?

The numbers change, but does the SHAPE of the output change?

Score: 3 if shape is identical every time. 1 if mostly stable. 0 if shape changes weekly.

4. How long does it currently take per cycle?

Score: 3 if 2-4 hours. 2 if 1-2 hours or 4-8 hours. 0 if <1 hour or >8 hours.

5. Where does the output go?

An internal Slack channel? An email to the team? A document? A customer? Be specific.

Score: 3 if internal. 1 if external-internal hybrid (e.g. drafts for a human to review and send). 0 if directly to customers (start with a different task first).

6. If it goes wrong by 5%, what happens?

Honest answer. Reversible inconvenience? Or a real consequence?

Score: 3 if reversible inconvenience. 1 if requires a small fix. 0 if has external consequences (regulatory, customer-facing, financial).

Step 4 · How to read your score

  • 15-18 · Strong candidate. Build it. Single-task scope, 2-4 weeks, fixed price.
  • 11-14 · Worth scoping. Tighten the task definition first; the gap to 15+ is usually a re-defining of scope, not a re-shaping of the work.
  • 7-10 · Marginal. The task probably needs to be broken into two distinct sub-tasks, with one of them being the actual agent candidate.
  • 0-6 · Wrong task for an agent. Don't try to force it. This work is human work. Look at your other candidate tasks.

Common red flags (do not ignore these)

Red flag 1. The task involves customer communication. Don't make this your first agent. Pick something internal-only for project 1, build trust, then revisit.
Red flag 2. "It's faster to just do it than explain it." This usually means the task isn't well-defined yet. The fix isn't AI; it's writing a clear spec.
Red flag 3. One of the data sources is "an email someone forwards me." Solvable, but not a first project. Pick a task with cleaner inputs.
Red flag 4. "It depends what's happening that week." This task has too much judgment in it. Pick something where the rules are stable.

Step 5 · One-paragraph project spec

If your highest-scoring task got 11+, fill this out:

"Every [when], an agent should pull [what data] from [which source(s)], transform it by [what rules], format it as [what output shape], and post it to [where]. If anything fails, ping [whom]."

If you can fill this out, you have enough to bring to any specialist for a build quote. You also have enough to build it yourself if you have someone in-house who codes.
